Проверка Web Push

Локальный диагностический стенд. Используйте тестовый аккаунт. Подписка относится к этому origin; основное PWA не изменяется.

Сначала войдите. Пароль и access token не сохраняются на диск.

«Проверить только показ ОС» не обращается к серверу и не проверяет push-доставку. Для полной проверки подпишитесь, добавьте продукты и назначьте сводку. Для повторной проверки назначьте другое будущее время.
